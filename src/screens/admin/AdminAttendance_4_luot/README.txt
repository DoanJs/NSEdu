Thay 4 file tương ứng trong module AdminAttendance. Chỉ thay frontend; không thay Cloud Functions, Firestore Rules hoặc dữ liệu. Bảng tháng chỉ tính ca đủ cả checkIn và checkOut; thời lượng là thời gian giữa hai dấu giờ máy chủ, không tự động khấu trừ nghỉ. Các bản ghi cũ chỉ có checkIn được giữ nguyên và tính là lượt chưa hoàn tất. Chạy npm run build trước khi đưa lên production.
